# AI 电商套图生成器：工具案例与使用说明

## 1. 工具简介

AI 电商套图生成器是一款面向跨境卖家、品牌方、电商运营和设计团队的商品图片生产工具。

用户上传一张商品参考图，选择目标电商平台并填写商品信息后，系统会按照平台规则推荐套图组合，自动生成对应的图片提示词，并批量生产白底主图、场景图、卖点图、参数图、模特图、促销图等电商素材。

一句话介绍：

> 选平台、传商品图、填卖点，一次生成一整套可继续编辑和下载的电商图片。

## 2. 适用场景

- 新品上架，需要快速补齐主图和详情页辅图。
- 同一商品需要适配 Amazon、Shopee、TikTok Shop、淘宝、天猫、京东等不同平台。
- 同一商品需要制作中文、英文、日文、韩文、西班牙文等多语言版本。
- SKU 较多，希望批量生成不同商品或不同颜色、规格的图片。
- 设计团队需要先快速产出可用初稿，再进行人工精修。
- 运营团队希望统一商品视觉风格，减少反复沟通提示词和版式要求。

## 3. 核心能力

### 3.1 平台规则预设

选择平台后，系统会自动带出：

- 推荐套图类型及顺序；
- 推荐导出尺寸；
- 默认文字语言；
- 图片信息密度；
- 主图、辅图的合规提示。

例如，Amazon 默认强调纯白底、少文字和清晰展示；淘宝、京东、拼多多更偏向卖点突出、参数完整的富信息图片。

### 3.2 商品参考图驱动

上传真实商品图后，AI 会参考商品的外形、颜色、材质和结构生成图片，尽量保持同一批套图中的商品一致性。

建议使用：

- 主体完整、无遮挡的商品图；
- 光线均匀、背景干净的图片；
- 分辨率较高、没有过度滤镜的原图；
- 与实际售卖 SKU 一致的图片。

### 3.3 多类型套图

当前套图覆盖七类常用电商视觉：

| 类别 | 常见图片 |
| --- | --- |
| 基础主图 | 白底主图、多角度展示、悬浮主图、透明去背图 |
| 场景生活 | 场景生活图、使用场景图、户外场景图、平铺俯拍图 |
| 模特实拍 | 模特展示图、模特特写图、竖版场景图 |
| 细节参数 | 细节特写、尺寸信息图、参数表、材质纹理、结构拆解图 |
| 营销卖点 | 卖点信息图、促销海报、场景卖点图、使用步骤图、对比图 |
| 信任卖点 | 认证资质图、服务保障图、品牌故事图、好评展示图 |
| 创意拓展 | 多色 SKU 图、包装展示图、套装组合图、创意氛围图 |

### 3.4 AI 提示词生成与人工编辑

系统会根据商品信息、参考图、平台、语言和所选套图，为每张图分别生成英文生图提示词。

提示词生成后仍可人工修改，适合补充：

- 必须出现的卖点；
- 禁止出现的元素；
- 特定场景、色调或构图；
- 图片中文字的准确表述；
- 品牌调性和活动主题。

### 3.5 多商品批量生产

可在同一个任务中添加多个商品。每个商品都可以单独设置：

- 参考图；
- 商品名称、类目、SKU 和规格参数；
- 目标平台、语言和信息密度；
- 套图类型；
- 每张图的提示词。

点击“批量生成”后，系统按照“商品 × 套图类型”并行提交任务，并展示每张图的生成进度。

## 4. 工具案例

### 案例：18V 无刷电钻 Amazon 上新套图

> 本案例用于展示操作方法和交付结构，不代表实际投放数据。

#### 业务需求

一家五金工具工厂准备在 Amazon 上架 18V 无刷电钻，希望快速制作一组英文商品图，覆盖主图、卖点、尺寸、使用场景和包装展示。

#### 准备素材

- 一张电钻白底或浅色背景正面图；
- 商品名称：18V Brushless Cordless Drill；
- 类目：Power Tools；
- SKU：CD-18V-PRO；
- 变体：Black, Red；
- 参数：电压 18V、最大扭矩 60N·m、夹头 13mm、电池 2×2.0Ah；
- 核心卖点：无刷电机、双速调节、LED 工作灯、轻量机身；
- 目标平台：Amazon；
- 图片语言：English；
- 信息密度：简洁少字。

#### 操作过程

1. 选择 Amazon，系统自动带出推荐套图。
2. 上传电钻参考图。
3. 填写商品名称、SKU、变体、参数和卖点。
4. 保留白底主图、卖点信息图、场景生活图、尺寸信息图、使用场景图、对比图和包装展示图。
5. 点击“AI 生成提示词（本商品）”。
6. 检查卖点和参数，确保数值、单位、语言准确。
7. 点击“批量生成”，等待所有图片完成。
8. 在生成结果中逐张查看并下载。

#### 预期交付

- 白底主图：商品居中、无文字、适合首图；
- 卖点信息图：突出无刷电机、扭矩和双速调节；
- 使用场景图：展示家装或木工作业；
- 尺寸信息图：标注机身尺寸或关键结构；
- 对比图：说明无刷方案与普通方案的差异；
- 包装展示图：展示电钻、双电池、充电器和工具箱。

#### 人工验收重点

- 商品颜色、结构、配件数量是否与实物一致；
- 参数、单位和图片文字是否准确；
- 主图是否符合平台无文字、白底等要求；
- 是否出现错误 Logo、错误型号或虚构配件；
- 不同图片中的商品外观是否保持一致。

## 5. 使用说明

### 步骤一：选择目标平台

在页面顶部选择目标平台。系统会应用该平台的推荐套图、文字密度和尺寸提示。

平台预设是生产起点，不替代最终的平台审核。正式发布前仍应以平台最新规则为准。

### 步骤二：上传商品参考图

点击“商品参考图”区域上传图片。没有参考图时也可以生成，但商品外观一致性通常会下降。

### 步骤三：填写商品信息

优先填写以下内容：

1. 商品名称和类目；
2. SKU、颜色和规格变体；
3. 关键参数；
4. 核心卖点；
5. 希望使用的风格、背景和场景；
6. 不希望出现的内容。

填写越具体，AI 越容易生成可执行的提示词。

### 步骤四：选择套图

可以直接使用“推荐套图”，也可以手动增减图片类型。

建议：

- 主图至少保留一张无文字的清晰商品图；
- 参数型商品增加参数表、尺寸图和结构拆解图；
- 服饰、美妆等类目增加模特图和细节图；
- 新品牌增加品牌故事、认证和服务保障图；
- 多颜色、多规格商品增加多色 SKU 图。

### 步骤五：生成并校对提示词

点击“AI 生成提示词（本商品）”。多商品任务也可以选择“为全部商品生成”。

生成后重点检查：

- 商品主体是否正确；
- 场景是否符合实际用途；
- 参数和卖点是否真实；
- 图片文字是否使用目标语言；
- 是否有不需要的品牌、人物或配件。

### 步骤六：批量生成

页面右上角会显示预计生成张数。点击“批量生成”后，系统会展示排队、生成、重试和完成状态。

若单张图片失败，系统会自动重试；达到重试上限后会显示失败原因，可修改提示词后重新生成。

### 步骤七：查看、下载和复用

- 点击结果图片可打开大图；
- 点击“查看 / 下载”保存图片；
- 已完成任务会进入浏览器本地历史记录；
- 历史记录适合快速回看，不建议作为唯一的长期素材存储方式。

## 6. 提示词填写建议

### 推荐写法

```text
保持参考图中的黑红色 18V 无刷电钻结构不变，展示在整洁的木工作业台上。
画面突出双速调节、LED 工作灯和 60N·m 最大扭矩。
整体为专业工具品牌风格，深灰背景，硬朗侧光。
图片文字使用英文，参数必须写为 18V 和 60N·m。
```

### 不推荐写法

```text
做得高级一点，好看一点，多一些卖点。
```

推荐提示词应包含主体、场景、卖点、构图、光线、文字语言和限制条件，避免只使用“高级”“好看”等模糊描述。

## 7. 常见问题

### 为什么同一商品的不同图片外观有差异？

参考图角度过少、商品被遮挡或提示词中加入了互相冲突的描述，都可能导致外观漂移。建议使用清晰参考图，并在每张提示词中明确要求保持商品结构、颜色和配件一致。

### 为什么图片文字不准确？

AI 图片中的文字仍需要人工检查。参数、价格、认证编号、品牌口号等关键信息，应在生成后核对，必要时交给设计人员二次排版。

### 为什么平台主图不能直接使用？

生成结果是素材初稿，平台规则会更新，且不同类目可能有额外限制。上架前应检查背景、文字、Logo、产品占比、尺寸和禁限售要求。

### 多商品任务如何避免配置混乱？

每添加一个商品后，逐个检查商品页签中的参考图、平台、语言、套图和提示词。批量生成前，以右上角显示的总张数做最后确认。

## 8. 使用边界

- 工具用于提高素材策划和初稿生产效率，不替代商品真实性审核。
- 不应生成虚假认证、虚构参数、错误功能或实际不包含的配件。
- 涉及价格、优惠、功效、医疗、美妆成分等内容时，应由业务人员和合规人员确认。
- 品牌 Logo、字体和最终版式可在生成后交由设计工具进行精修。
- 正式投放前，应按目标平台的最新政策进行人工验收。
