# 图匠 AI 图片工作台：工具案例与使用说明

## 1. 工具简介

图匠是一套面向电商运营、品牌团队、设计人员和工厂业务人员的 AI 图片工作台，不只用于生成电商套图，还包含三类核心能力：

1. **批量去水印**：清理覆盖在图片上的水印、Logo、网址、促销文字和装饰元素；
2. **超清图片**：对模糊、低清、有噪点的图片进行清晰度增强；
3. **套图生成**：根据商品参考图、平台规则和卖点，批量生成主图、场景图、参数图和营销图。

一句话介绍：

> 从旧素材清理、图片变清晰，到电商套图生产，在一个工作台内完成商品图片的整理和再创作。

## 2. 适用场景

- 供应商提供的图片带有渠道水印、网址或促销文字，需要整理成可再次使用的干净素材；
- 历史产品图分辨率低、细节模糊，需要增强后用于详情页、展会资料或销售沟通；
- 新品上架，需要快速补齐白底主图、场景图、卖点图、参数图和包装图；
- 同一商品需要适配 Amazon、Shopee、TikTok Shop、淘宝、天猫、京东等不同平台；
- SKU 较多，需要按商品、颜色、规格或目标市场批量生产图片；
- 视频生成前需要先整理图片素材，提高产品图和工厂图的可用性。

## 3. 功能总览

| 功能 | 输入 | 主要处理 | 输出 |
| --- | --- | --- | --- |
| 批量去水印 | 商品图、海报、供应商图片 | 移除覆盖文字、水印、网址、外加 Logo 等 | 干净图片 |
| 超清图片 | 模糊图、低清图、压缩图 | 去噪、去模糊、锐化边缘、增强纹理和文字清晰度 | 高清图片 |
| 套图生成 | 商品参考图、参数、卖点、平台 | 生成提示词并按套图类型批量生图 | 电商主图、辅图和营销素材 |

三个功能可以单独使用，也可以组成一条连续流程：

```text
原始图片
→ 去水印
→ 超清处理
→ 作为商品参考图
→ 生成电商套图
→ 进入素材中心继续生成视频
```

## 4. 批量去水印

### 4.1 功能说明

批量去水印用于清除覆盖在图片上的非商品内容，例如：

- 半透明水印；
- 店铺名称或网址；
- 外加 Logo；
- 价格、活动口号和促销标签；
- 海报边框、横幅和装饰文字。

系统的处理原则是：清除图片外加元素，同时尽量保护商品本身、包装、构图、颜色、光影和方向。

商品包装上原本就存在的品牌、型号、参数和图案属于商品内容，不应作为水印删除。若系统难以判断，必须人工复核。

### 4.2 核心能力

- 点击或拖入多张图片进行批量处理；
- 创建多个独立任务；
- 保持原图比例，或选择 `1:1`、`4:3`、`3:4`、`3:2`、`2:3`、`16:9`、`9:16`；
- 填写自定义处理要求；
- 查看单张图片和整个任务的进度；
- 失败自动重试；
- 对失败图片单独重试或批量重试；
- 将全部成功图片打包为 ZIP 下载；
- 切换功能页或刷新后继续查看本地保存的任务状态。

### 4.3 使用步骤

1. 登录图匠，选择“批量去水印”；
2. 点击“新建任务”；
3. 点击或拖入需要处理的图片；
4. 选择出图比例，默认建议使用“原图比例”；
5. 如有特殊要求，在“自定义需求”中补充；
6. 点击“开始去水印”；
7. 查看处理进度和失败原因；
8. 对失败图片执行重试；
9. 逐张验收后，点击“下载全部”打包保存。

### 4.4 自定义需求示例

```text
清除背景、边框和图片角落中的全部宣传文字与网址，
保留商品包装上原有的品牌、型号、参数和图案，
保持商品方向、颜色、构图和阴影不变。
```

### 4.5 案例：清理供应商产品海报

**原始问题**

一组电钻供应商图片带有店铺网址、活动价格、半透明 Logo 和海报边框，但产品包装上的品牌和参数需要保留。

**操作**

1. 将图片放入同一个去水印任务；
2. 选择原图比例；
3. 填写“删除外部网址、促销价格和角落 Logo，保留产品及包装文字”；
4. 批量处理；
5. 检查钻机结构、包装文字和配件数量；
6. 对不符合要求的图片修改说明后重试。

**交付**

- 可继续用于设计排版的干净产品图；
- 可进入超清处理的基础图片；
- 可作为电商套图或视频生成的参考素材。

## 5. 超清图片

### 5.1 功能说明

超清图片用于增强原图的清晰度，重点处理：

- 低分辨率；
- 压缩噪点；
- 轻度或明显模糊；
- 边缘不清；
- 表面纹理缺失；
- 图片中的参数和标签难以辨认。

系统目标是保持原有主体、文字、布局、颜色、背景和方向不变，只提高锐度、分辨率和细节表现。

### 5.2 核心能力

- 多图批量增强；
- 原图比例或常用横竖版比例输出；
- 去噪、去模糊和边缘增强；
- 强化产品纹理、标签和参数可读性；
- 进度追踪、失败重试和 ZIP 批量下载；
- 支持通过自定义需求强调某些细节。

### 5.3 使用步骤

1. 选择“超清图片”；
2. 新建任务并上传低清图片；
3. 选择出图比例；
4. 填写需要重点增强的内容；
5. 点击“开始超清处理”；
6. 对比原图与结果图；
7. 检查文字、结构和颜色是否发生变化；
8. 下载合格图片。

### 5.4 自定义需求示例

```text
重点增强电钻金属夹头、机身防滑纹理和电池标签，
保持黑红配色、产品方向、背景、参数文字和构图不变，
不要增加原图中不存在的零件或装饰。
```

### 5.5 案例：低清目录图用于销售资料

**原始问题**

产品目录中只有一张经过压缩的电动工具图片，边缘模糊，电池标签和机身纹理不清晰。

**操作**

1. 上传目录图；
2. 使用原图比例；
3. 要求重点增强机身纹理、夹头边缘和电池标签；
4. 完成后放大检查产品结构和文字；
5. 合格图片用于产品手册、客户报价资料或素材中心。

**验收重点**

- 型号和参数不能被 AI 改写；
- 原本无法辨认的文字不应被当作真实信息直接使用；
- 不应出现新增按钮、接口、配件或虚构纹理；
- 人物、商品和场景方向不能被翻转。

## 6. 电商套图生成

### 6.1 功能说明

用户上传商品参考图，选择目标电商平台并填写商品信息后，系统会按照平台规则推荐套图组合，为每种图片类型生成提示词，并批量生产电商素材。

### 6.2 平台规则预设

选择平台后，系统会带出：

- 推荐套图类型及顺序；
- 推荐导出尺寸；
- 默认文字语言；
- 图片信息密度；
- 主图和辅图的合规提示。

例如，Amazon 更强调纯白底、少文字和商品清晰展示；淘宝、京东和拼多多更偏向卖点突出、参数完整的富信息图片。

### 6.3 套图类型

| 类别 | 常见图片 |
| --- | --- |
| 基础主图 | 白底主图、多角度展示、悬浮主图、透明去背图 |
| 场景生活 | 场景生活图、使用场景图、户外场景图、平铺俯拍图 |
| 模特实拍 | 模特展示图、模特特写图、竖版场景图 |
| 细节参数 | 细节特写、尺寸信息图、参数表、材质纹理、结构拆解图 |
| 营销卖点 | 卖点信息图、促销海报、场景卖点图、使用步骤图、对比图 |
| 信任卖点 | 认证资质图、服务保障图、品牌故事图、好评展示图 |
| 创意拓展 | 多色 SKU 图、包装展示图、套装组合图、创意氛围图 |

### 6.4 使用步骤

1. 选择“套图生成”；
2. 创建商品图片库；
3. 上传一张或多张商品参考图；
4. 填写商品名称、类目、SKU、变体、规格、卖点和限制条件；
5. 选择目标平台、图片语言、信息密度和画质；
6. 使用平台推荐套图，或人工增减图片类型；
7. 点击 AI 生成提示词；
8. 检查每张图的主体、参数、文字和场景；
9. 点击批量生成；
10. 查看进度、重试失败任务并下载结果。

### 6.5 案例：18V 无刷电钻 Amazon 上新

> 本案例用于说明操作方法和交付结构，不代表实际投放效果。

**商品信息**

- 商品名称：18V Brushless Cordless Drill；
- SKU：CD-18V-PRO；
- 颜色：Black, Red；
- 参数：18V、60N·m、13mm 夹头、2×2.0Ah 电池；
- 卖点：无刷电机、双速调节、LED 工作灯、轻量机身；
- 目标平台：Amazon；
- 图片语言：English；
- 信息密度：简洁少字。

**操作**

1. 将去水印、超清后的电钻图作为参考图；
2. 选择 Amazon；
3. 填写商品参数和卖点；
4. 选择白底主图、卖点信息图、场景图、尺寸图、对比图和包装图；
5. 生成并校对提示词；
6. 批量生图；
7. 检查产品结构、配件数量、参数和英文文字；
8. 下载合格图片。

**预期交付**

- 白底主图；
- 卖点信息图；
- 木工作业场景图；
- 尺寸或结构信息图；
- 产品方案对比图；
- 包装和配件展示图。

## 7. 图片工具与素材中心的协同流程

图匠适合负责“图片清理和图片生产”，AdPilot 素材中心适合负责“资料沉淀和视频生产”。

推荐流程：

```text
供应商图片 / 工厂旧资料
→ 图匠批量去水印
→ 图匠超清处理
→ 图匠生成电商套图
→ 上传 AdPilot 原始素材库
→ 生成 Factory Profile 和客户画像
→ 生成工厂视频、单品视频或纯 AI 视频
→ 成片进入“我的素材”
→ 下载、投放或导入商机中心知识库
```

这样可以先提高图片素材质量，再让画像、脚本、分镜和视频生成流程引用更清晰、更准确的产品资料。

## 8. 通用验收清单

### 8.1 真实性

- [ ] 商品型号、结构、颜色和配件数量正确；
- [ ] 参数、单位、认证和功效有真实依据；
- [ ] 没有新增原图不存在的部件或功能；
- [ ] 没有虚构品牌、客户、奖项或合作案例。

### 8.2 图片质量

- [ ] 去水印后背景修补自然；
- [ ] 商品和包装上的原生文字被正确保留；
- [ ] 超清后没有错误文字、过度锐化或塑料感；
- [ ] 图片没有翻转、裁切主体或改变商品方向；
- [ ] 套图中的商品外观保持一致。

### 8.3 平台与业务用途

- [ ] 主图背景、文字和产品占比符合平台要求；
- [ ] 图片比例和尺寸适合目标渠道；
- [ ] 多语言文字已经人工校对；
- [ ] 正式发布前已由运营、设计或业务人员确认。

## 9. 常见问题

### 去水印时为什么删除了商品包装上的文字？

包装文字与外部水印距离过近，或自定义要求不够明确时，可能出现误删。应明确写出“保留商品和包装内部的品牌、型号和参数”，并在处理后逐张检查。

### 去水印能否用于没有使用权的图片？

不能。工具只用于处理企业拥有或已获授权使用的素材，不应通过去水印规避版权、品牌或平台规则。

### 超清后文字为什么与原图不一致？

AI 会尝试重建模糊细节，但无法保证恢复原本不可辨认的文字。型号、参数、价格和认证编号必须以真实资料为准，必要时由设计人员重新排版。

### 为什么套图中的商品外观有差异？

参考图角度不足、商品被遮挡，或提示词之间存在冲突，都可能导致外观漂移。建议先使用清晰参考图，并在提示词中明确保持商品结构、颜色和配件一致。

### 批量任务如何避免混乱？

按商品或用途建立独立任务，统一命名；开始前确认图片数量、出图比例、平台、语言和套图类型；下载后按项目、SKU 和日期归档。

## 10. 使用边界

- 工具用于提高图片整理和内容生产效率，不替代版权审核、事实审核和平台合规审核；
- 不应删除用于证明版权归属或来源的标记后冒充自有素材；
- 不应生成虚假认证、虚构参数、错误功效或实际不包含的配件；
- AI 无法可靠恢复原图中完全不可辨认的信息；
- 品牌 Logo、关键文字和正式版式建议由设计人员进行最终精修；
- 正式投放前，应按照目标平台最新政策进行人工验收。
